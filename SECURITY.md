# Security policy

This repository is a public template. Do not report a suspected secret, account compromise, or exploitable vulnerability with real personal data in a public issue.

Before deployment, the operator must replace `[PRIVATE SECURITY CONTACT]` with a private reporting channel and keep it out of the anonymized public source if necessary.

Do not include passwords, session secrets, API keys, wallet keys, seed phrases, private URLs, database copies, or chat exports in reports.

The project is not a certified high-security or compliance system. Production operators are responsible for TLS, patching, backups, secret rotation, logging, monitoring, account deletion, and legal review.
